# Soạn chữ mẫu trên giấy ô li

Soạn mẫu chữ cho lớp 1 cùng thầy Hợi. Ứng dụng chạy hoàn toàn trên trình duyệt, không cần máy chủ.

Phát triển bởi thầy Hợi - Trường Tiểu học Bảo Đài 2, TP Bắc Ninh - 0967 834 824

## Các file

- `index.html`: giao diện
- `style.css`: kiểu dáng
- `app.js`: toàn bộ chức năng
- `logo.png`: logo (muốn đổi logo, chép ảnh vuông mới đè lên, giữ đúng tên `logo.png`)

## Đưa lên GitHub Pages

1. Vào github.com, bấm **New repository**, đặt tên (ví dụ `soan-chu-mau`), chọn **Public**, bấm **Create repository**.
2. Bấm **uploading an existing file**, kéo cả 4 file trên vào, bấm **Commit changes**.
3. Vào **Settings** > **Pages**. Mục **Source** chọn **Deploy from a branch**, nhánh **main**, thư mục **/ (root)**, bấm **Save**.
4. Chờ 1 đến 2 phút. Địa chỉ trang sẽ là `https://TEN-GITHUB.github.io/soan-chu-mau/`.

Khi muốn sửa, chỉ cần tải file mới đè lên file cũ trong kho GitHub.
